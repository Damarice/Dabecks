# Dabecks Laundry & Kitchen Solutions Website

Professional Next.js website for Dabecks Laundry & Kitchen Solutions Limited, East Africa's trusted provider of commercial laundry, kitchen, and air conditioning systems.

## 🚀 Features

- **Modern Next.js 16** with TypeScript and Tailwind CSS
- **Responsive Design** - Works seamlessly on all devices
- **Professional Layout** - Clean, modern design inspired by industry standards
- **Complete Page Structure**:
  - Home page with hero section and company overview
  - About Us with mission, vision, values, and journey
  - Solutions pages (Laundry, Kitchen, Air Conditioning, Consultancy)
  - Clients page showcasing partnerships
  - Partners page featuring equipment brands and service alliances
  - Contact page with form and company details

## 🛠️ Tech Stack

- **Framework**: Next.js 16.3.2
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **React**: 19.2.8

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```
